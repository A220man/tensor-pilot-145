# Tensor-Pilot-145\n\n## Overview\nTensor-Pilot-145 is a **Universal SEO skill for Claude Code** providing comprehensive data fetching and analysis capabilities.\n\n## Features\n- Keyword analysis with search volume, difficulty scores, and CPC\n- SERP data fetching with domain authority and page rank\n- Advanced caching for performance optimization\n- Real-time monitoring and statistics\n\n## Quick Start\n\n### Prerequisites\n- Python 3.7+\n- FastAPI and related dependencies\n\n### Installation\n```bash\n# Install dependencies (if needed)\npip install fastapi uvicorn pydantic python-multipart\n\n# Create virtual environment (recommended)\npython3 -m venv venv\nsource venv/bin/activate  # On Windows: venv\\Scripts\\activate\npip install -r requirements.txt\n```\n\n### Running the Application\n```bash\npython main.py\n```\n\nOr with uvicorn:\n```bash\nuvicorn main:app --host 0.0.0.0 --port 8000\n```\n\n### Web Interface\nOpen `web-interface.html` in a web browser to test the API interactively.\n\n## API Endpoints\n\n### Basic Endpoints\n- `GET /` - API information and capabilities\n- `GET /health` - Health check\n- `GET /ready` - Readiness check\n- `GET /stats` - API statistics\n\n### SEO Data Endpoints\n- `POST /api/seo/keyword/analyze` - Analyze keyword and fetch SERP data\n- `GET /api/seo/keyword/{keyword}` - Get cached keyword analysis\n- `GET /api/seo/cache/stats` - Get cache statistics\n- `GET /api/seo/health` - SEO API health check\n\n### Keyword Analysis Example\n```bash\ncurl -X POST http://localhost:8000/api/seo/keyword/analyze \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"keyword\": \"SEO optimization\",\n    \"location\": \"US\",\n    \"language\": \"en\",\n    \"limit\": 10\n  }'\n```\n\n## Testing\n\n### Run
